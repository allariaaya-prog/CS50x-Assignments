# CS50x-Assignments
My journey through CS50x — a collection of problem sets and projects from Harvard’s Introduction to Computer Science.

## Projects Included
**Mario**: Pyramid-building project to practice loops and conditionals.
**Cash**: Program to calculate change using algorithms.

**Readability**: Computes text readability using the Coleman-Liau index.
**Caesar**: Implements the Caesar cipher for text encryption.

**Plurality**: Implements a voting program to determine the winner.
**Runoff**: Implements a runoff voting system.

**Cash (Python version)**: Same as Week 1 project but in Python.
**Other Python scripts**: Various exercises to practice Python syntax.
**Other SQL scripts**: Various exercises to practice SQL syntax.


## Technologies Used
C, Python.

## Notes
Each project is contained in its own folder with source code and instructions.
